# 초등 서논술형평가 문항 개발 도우미 · PDF 양식 고도화 버전

## 핵심 변화
업로드된 「서논술형 평가 자료 개발 약안」의 3쪽 구성을 웹 결과 화면에 반영했습니다.

1. **평가 개발 약안**
   - 교과 / 영역 / 유형
   - 단원명(차시)
   - 성취기준
   - 공식 A·B·C 성취수준
   - 평가 요소 3개
   - 평가 과제 3개
   - 평가시 유의 사항
   - 문항별 분석적 채점기준

2. **예시답안 및 수준별 피드백**
   - 과제 1~3 예시답안
   - 상·중·하 수준별 피드백

3. **학생용 서·논술형 평가 과제**
   - 단원(차시), 평가 요소 요약
   - 문항 1~3
   - 문항별 배점
   - 자료, 발문, 조건, 답안 작성선
   - 그림 자료가 필요한 경우 삽입 위치 표시

## 구조 개선
기존 Markdown 생성 방식 대신 Gemini가 **구조화된 JSON 평가안**을 반환하도록 변경했습니다.
따라서 표·채점기준·학생용 문항을 PDF 양식과 비슷한 형태로 안정적으로 렌더링합니다.

## 추가 입력 항목
- 학기(선택)
- 영역(선택)
- 단원명(차시)(선택)

단원명과 영역은 교과서나 수업 맥락에 따라 달라질 수 있으므로 자동으로 사실처럼 생성하지 않습니다.

## PDF
- **전체 PDF**: 평가 개발 약안 + 예시답안·피드백 + 학생용 평가 과제
- **학생용 PDF**: 학생용 평가 과제만 출력

## 그림 자료
AI가 그림이 꼭 필요하다고 판단한 문항은 학생용 과제에 `그림 자료 삽입 영역`이 표시됩니다.
실제 이미지 생성용 프롬프트는 결과 화면 아래에 별도로 제공되며 학생용 PDF에는 포함되지 않습니다.

## 데이터
`public/data/standards.json`에는 1~6학년군 총 611개 성취기준과 공식 성취기준별 A·B·C 성취수준이 포함되어 있습니다.

## Netlify 환경 변수
- `GEMINI_API_KEY` : 필수
- `GEMINI_MODEL` : 선택, 기본값 `gemini-3.6-flash`

API Key는 브라우저에 넣지 않고 Netlify Function에서만 사용합니다.

## 배포 구조
```
├─ netlify.toml
├─ README.md
├─ public/
│  ├─ index.html
│  ├─ assets/
│  │  └─ jeonnam-gwangju-logo.png
│  └─ data/
│     └─ standards.json
└─ netlify/
   └─ functions/
      └─ generate.js
```

GitHub 저장소의 같은 위치에 파일을 덮어쓴 뒤 커밋하면 Netlify가 자동 재배포합니다.


## 2026-09 레이아웃 및 비용 최적화
- 예시답안·피드백 표에서 '중/하' 피드백 문장이 한 글자씩 세로로 깨지던 CSS Grid 구조를 수정했습니다.
- 채점기준의 상·중·하와 설명 문장이 항상 같은 행에 맞도록 표 구조를 보강했습니다.
- 한글 문장은 `word-break: keep-all`을 적용해 자연스러운 어절 단위 줄바꿈을 우선합니다.
- 학생용 평가 과제가 길면 compact/tight 모드가 자동 적용되어 A4 한 쪽에 우선 맞춥니다.
- 기본 Gemini 모델을 `gemini-2.5-flash-lite`로 변경했습니다.
- Netlify 환경변수 `GEMINI_MODEL`이 별도로 설정되어 있다면 그 값이 우선합니다.
  비용 최적화를 원하면 `GEMINI_MODEL`을 삭제하거나 `gemini-2.5-flash-lite`로 설정하세요.


## 생성 품질 선택
웹 화면에서 두 가지 생성 방식을 선택할 수 있습니다.

- 기본 생성: `gemini-3.5-flash-lite`
  - 빠른 응답과 낮은 비용을 우선합니다.
  - thinkingLevel: `minimal`
  - 일반적인 서·논술형 평가 문항 생성의 기본값입니다.

- 고품질 생성: `gemini-3.8-flash`
  - 복합 자료형 문항, 문항 간 연결, 채점기준 정교화를 우선합니다.
  - thinkingLevel: `medium`
  - 기본 생성보다 응답 시간과 비용이 증가할 수 있습니다.

### 선택 환경변수
필요하면 Netlify에서 모델을 따로 바꿀 수 있습니다.

- `GEMINI_MODEL_BASIC`
- `GEMINI_MODEL_HIGH`

기존 `GEMINI_MODEL` 환경변수는 이 버전에서는 사용하지 않습니다.
